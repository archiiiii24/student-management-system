 Student Course & Academic Management System

 1. Problem Statement

Manually managing information about students’ academic details may prove to be a challenge, especially when it comes to storing and organizing information about students, courses, enrollments, and grades. Additionally, searching and calculating academic performance may be cumbersome.

Student Course & Academic Management System is a java application that helps manage students’ basic information in a more organized manner. Using the application, a user can store details about students, manage course catalogues, record enrollment and grades, and view academic reports with calculated GPA.

2. Project Scope

Student Course & Academic Management System aims to solve the basic academic management problems faced by a student.
Features within the scope of the project include:

Student management

Course management
Enrollment recording
Grade recording

Grade points calculation
Academic report generation
GPA calculation

Text file storage
The project is a command line java application that employs the use of object-oriented and file handling concepts.
 3. Target Users
The application can be useful to:
Students managing their academic information,
Faculty members managing basic course and grade information
Small private institutions using the basic records management functionalities
 4. High-Level Features
### Student Management
Student information such as student ID, name, and contact can be added to the application database. Student information can be viewed and searched using the student ID.
### Course & Enrollment Management
The application allows course information recording, viewing, and searching using the course ID. Enrollments can also be recorded using the student and course IDs.
### Academic Performance Management
Academic performance can be recorded using the student ID, course ID, and grade. The application converts letter grades to grade points, calculates weighted grade points using credit hours, generates academic reports, and calculates GPA.
### File Storage

The application stores student records in students.txt, course records in courses.txt, enrollment records in enrollment.txt, and grade records in grades.txt.
